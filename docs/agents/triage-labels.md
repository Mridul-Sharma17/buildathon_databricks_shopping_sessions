| Role and GitHub label | Meaning |
|---|---|
| `needs-triage` | A maintainer needs to review the issue. |
| `needs-info` | The issue needs more information from the reporter. |
| `ready-for-agent` | The issue is specified and ready for an agent. |
| `ready-for-human` | A human needs to implement the issue. |
| `wontfix` | The issue is closed without planned work. |
